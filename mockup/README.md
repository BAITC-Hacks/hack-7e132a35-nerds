# Макет «Аким на 5 часов»

## Запуск

Скачайте ZIP этой ветки репозитория, распакуйте и откройте `mockup/index.html` в современном браузере. Установка пакетов, API-ключ и сервер не нужны. GitHub отображает HTML как код; это не опубликованный сайт.

## Что доступно

- Русский интерфейс с подписями чисел и единиц измерения.
- Матрица всех мероприятий по всем районам, объёмы и общий бюджет.
- Прогноз индекса качества жизни и результаты по районам.
- Раздел «Данные города»: Excel/CSV, скачивание шаблонов, предварительный просмотр и проверка.
- Применение данных создаёт новый сценарий; предыдущий можно открыть через список версий.

## Как попробовать

1. Откройте «Данные города» и нажмите «Пример заполнения».
2. Просмотрите листы «Районы», «Мероприятия», «Эффекты и ограничения», «Настройки».
3. Подтвердите создание нового сценария и нажмите «Применить данные».
4. На вкладке «План мероприятий» выберите ячейку и задайте объём.
5. Нажмите «Оценить сценарий», чтобы увидеть расчёт по районам.
6. Вернитесь к предыдущему сценарию через список версий.

## Файлы и формат импорта

- `index.html` — самостоятельный экспорт для браузера.
- `akim-city-planner.fragment.html` — исходный фрагмент последнего макета; самостоятельно без окружения не запускается.

Excel содержит четыре листа с точными именами: `Районы`, `Мероприятия`, `Эффекты`, `Настройки`. CSV в UTF-8 заменяет один лист черновика; тип определяется по заголовкам. После последовательной загрузки связанных CSV применяется весь проверенный набор.

Ограничения макета: файл до 1 МБ, до 10 районов, 20 мероприятий, 200 связей. Каждая пара район/мероприятие должна присутствовать на листе «Эффекты». Максимум шагов — от 0 до 3; 0 означает недоступность мероприятия. Цена за шаг и бюджет — положительные целые условные единицы; показатели — от 0 до 100.

## Ограничения

Это интерактивный прототип, не готовая серверная система.

- AI не подключён: «Советник акима» использует локальные правила.
- Файлы обрабатываются в браузере; данные и история версий существуют только в текущем сеансе. Обновление страницы сбрасывает сценарии.
- Надпись «Режим организатора» демонстрирует интерфейс и не означает наличие авторизации.
- В расчёте используется среднее пяти показателей по районам с равными весами. Население хранится, но пока не влияет на веса.
- Данные учебные; индекс не является официальным городским показателем.
- Для Excel требуется интернет: модуль SheetJS 0.18.5 загружается с jsDelivr. При недоступности CDN можно использовать CSV и встроенный пример. Другие ресурсы оболочки также могут требовать интернет.
- В прототипе нет серверной проверки, базы данных или постоянного хранения.

## Проверка

Проверен синтаксис JavaScript исходника. В браузере проверены предпросмотр примера, блокировка применения до подтверждения и создание версии 2 с бюджетом 120 вместо 100. Произвольные пользовательские Excel/CSV и все браузеры не проходили отдельную полную проверку.
