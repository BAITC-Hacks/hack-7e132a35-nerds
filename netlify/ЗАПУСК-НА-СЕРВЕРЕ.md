# Развёртывание на Netlify

Для текущего проекта предназначена инструкция [NETLIFY-QUICKSTART.md](NETLIFY-QUICKSTART.md). Она охватывает базу данных, подключение GitHub, переменные окружения, публикацию и проверку авторизации.

В репозитории сохранены Docker-файлы для отдельного VPS-сценария. Файл `.env.production.example` содержит только пример настроек: замените адрес базы и другие параметры на свои, создайте собственные секреты и не публикуйте их. Не переносите реальные `.env` файлы из старых архивов.
