# «Аким на 5 часов» — версия для Netlify

Проект содержит сайт Next.js с серверной авторизацией, PostgreSQL и симулятором городского бюджета. Для Netlify нужно собирать весь проект через подключённый GitHub-репозиторий. Загрузка готовых файлов через Netlify Drop не запускает серверные API и авторизацию.

## Быстрый запуск

1. Создайте внешнюю PostgreSQL-базу и выполните в ней SQL из `db/001_auth.sql`.
2. Подключите GitHub-репозиторий к Netlify. Корень проекта — папка с этим README и `package.json`.
3. Добавьте переменные окружения, указанные в `NETLIFY-QUICKSTART.md`.
4. Запустите Deploy. Проверьте `/api/health`, затем зарегистрируйте аккаунт на сайте.

Подробная инструкция: [NETLIFY-QUICKSTART.md](NETLIFY-QUICKSTART.md).

## Локальная проверка

Требуется Node.js 22.12+ и pnpm:

```sh
pnpm install --frozen-lockfile
pnpm test:model
pnpm build
```

Сценарии симулятора хранятся в браузере аккаунта. PostgreSQL хранит пользователей и сессии. AI-разбор пока не подключён: объяснение результатов строится по формулам.

## Безопасность

Не публикуйте `.env.local`, `.server.env`, `.review.env`, резервные копии базы или другие реальные секреты. Они исключены из подготовленной Netlify-поставки. Если старые реквизиты базы загружались в общий архив или репозиторий, смените пароль базы и удалите старые секреты из истории публикаций.
