# Аким на 5 часов

Локальный симулятор на Python 3.9+ и HTML/CSS/JavaScript, без сторонних зависимостей. Исходный `akim-mockup.html` сохранен как референс.

## Запуск

```sh
python3 server.py
```

Откройте http://localhost:8000. Для другого порта: `PORT=8080 python3 server.py`.

## AI-анализ

Задайте `OPENAI_API_KEY` в окружении сервера и перезапустите его. Не добавляйте ключ в исходники или браузер. Файл `.env` автоматически не загружается. Модель задаётся `OPENAI_MODEL`, по умолчанию `gpt-4.1-mini`; она должна быть доступна вашему API-проекту.

Сервер отправляет рассчитанный сценарий и синтетический каталог в OpenAI Responses API, `store=false`. Интеграция основана на [официальной документации](https://developers.openai.com/api/docs/guides/text). AI объясняет сильные стороны, риски, последствия и компромиссы; численный индекс рассчитывает сервер. Без ключа или при ошибке API отображается явно обозначенный расчетный разбор. Реальный вызов API требует собственного ключа и не включён в автоматические тесты.

## Правила

- Все начинают с бюджетом 100 условных единиц и датасетом `astana-synthetic-v1`.
- Ровно одно мероприятие на каждое из пяти направлений. Для каждого выбираются район и масштаб ×1–×3.
- Сервер проверяет стоимость по собственному каталогу. Подмена бюджета в запросе не работает.
- Эффекты, включая отрицательные, суммируются по району. Затем показатели ограничиваются диапазоном 0–100.
- Индекс района — среднее пяти показателей. Индекс города — среднее индексов районов, взвешенное по населению. Округление только при отображении.
- Исходный индекс: 48,02. Это учебная модель, не официальный городской показатель и не прогноз.

Районы, население, стоимость, эффекты и риски находятся в `model.py`. В интерфейсе доступны исходные показатели, предварительная оценка, итоговые диаграммы и экспорт отчёта JSON. Сценарий хранится в памяти вкладки; при перезагрузке начинается новая попытка. Сравнение команд и постоянное хранение не реализованы.

## Проверка

```sh
python3 -m unittest discover -s tests -v
```

Тесты проверяют одинаковый старт, формулу, изменение результата, независимость от порядка решений, ограничения, точный расход бюджета, серверную защиту от подмены, обработку AI и HTTP-сценарий. API замокан.

Для демонстрации выберите первые мероприятия всех пяти направлений: стоимость 54. Увеличьте транспорт и озеленение до ×3: стоимость 98. Попытка увеличить социальную инфраструктуру до ×3 отклоняется. Нажмите «Оценить сценарий», затем измените район и повторите оценку.

Сервер предназначен для локального хакатон-прототипа и слушает только 127.0.0.1. Для публичного размещения нужны production-сервер, аутентификация и ограничение запросов к платному AI.
