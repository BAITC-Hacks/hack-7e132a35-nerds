# Проверка Netlify-поставки

Проверяемый источник: `akim-server-deploy-netlify.zip`. Дата: 23 сентября 2026 года. Это отдельная версия; результаты тестов предыдущего архива сюда не перенесены.

## Подтверждено

- Установка зависимостей по frozen lockfile.
- Production-сборка Next.js 16.3.6 на Node 24.19.0, macOS arm64.
- В tracing-манифестах обоих маршрутов `/simulator` присутствуют index.html, app.js и model.js.
- Тесты модели: начальный балл 52.55768, контрольный план 95 единиц / около 56.54 балла; число решений, бюджет, уникальность меры, максимум две меры направления, охват, несовместимости, синергия, независимость от порядка, порог 40 и сумма долей населения.
- Миграция на отдельной пустой PostgreSQL 17.10.
- Все 12 проверок авторизации на PostgreSQL: хеширование, роли, сессии, неверный пароль, блокировка, истечение, выход, ограничения попыток, Origin и cookies.
- Восстановление синтетической копии users, sessions и auth_limits в изолированной тестовой схеме.
- Полный HTTP-тест: регистрация, вход, cookie, текущий пользователь, защищённый симулятор и ресурсы, Origin, выход.
- Браузер: вход и сбор контрольного плана M7+M8+M10+M12+M5. Балл 56,54, расходы 95, средний 58,08, худший 52,96, критических показателей 0; синергия M10+M12 в Нуре.
- После перезагрузки браузера контрольный план восстановился с баллом 56,54.
- Синтаксис shell-скриптов проверен; запуск Docker/VPS не выполнялся.

## Исправления в проверенной копии

1. Закреплён pnpm 11.19.0, Netlify Node 24 и PNPM_FLAGS=--shamefully-hoist по документации платформы.
2. Health endpoint теперь проверяет чтение таблиц авторизации; прежний SELECT 1 мог вернуть ok при отсутствующей схеме.
3. Тест восстановления больше не требует приватного backup/database.json: использует синтетические записи.
4. Добавлены регрессионные проверки текущих правил модели и команда test:snapshot.
5. Переписан README: фактическая архитектура, запуск, конфигурация, формула, пример результата и ограничения. Основная модель не заменялась кодом из другого архива.

## Обнаруженные ограничения

| Приоритет | Факт | Следствие |
|---|---|---|
| Высокий | AI-вызовов в проекте нет | Обязательное требование AI-анализа пока не выполнено |
| Высокий | Бюджет и Score рассчитываются только на клиенте | Нельзя доверять результатам для соревнования без серверной проверки |
| Высокий | Импорт набора доступен участнику | Единые условия не закреплены сервером |
| Высокий | Пять мер не гарантируют пять направлений | В контрольном примере четыре направления; правило нужно согласовать |
| Средний | Планы хранятся только в localStorage | Нет серверного сохранения или общего рейтинга команд |
| Средний | Публичный Netlify deploy не выполнен | Локальный build не доказывает работу адаптера, сети, SSL и переменных в облаке |

## Не проверено / требует внешней среды

Реальный Netlify deploy, внешняя PostgreSQL/Supabase и её TLS/права, Docker Compose, Caddy/HTTPS на VPS и PowerShell-скрипты Windows. Это не полноценный аудит безопасности или нагрузочное тестирование. Файлы с действующими паролями и база пользователей в новую поставку не включены.

Перед сдачей повторите контрольный сценарий на опубликованном URL и проверьте регистрацию, выход, 401 без сессии, 403 с неверным Origin, health, загрузку симулятора и сохранение в браузере.
