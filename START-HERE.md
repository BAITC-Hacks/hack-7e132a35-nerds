# Начните с этого файла

Чтобы опубликовать сайт на Netlify, следуйте инструкции [NETLIFY-QUICKSTART.md](NETLIFY-QUICKSTART.md).

В двух словах: нужна внешняя PostgreSQL-база с применённым `db/001_auth.sql`, подключение полного GitHub-репозитория к Netlify и серверные переменные окружения. Просто перетащить HTML-папку в Netlify Drop недостаточно для авторизации и API.

Подготовленная поставка не содержит паролей баз данных, резервных копий, `.env.local` или `.server.env`.
